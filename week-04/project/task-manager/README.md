
# Task Manager

Aplicación de tareas desarrollada con React y TypeScript.

## Tecnologías

- React
- TypeScript
- Vite
- Fetch API

## Funcionalidades

- Consulta de tareas desde una API.
- Búsqueda por título.
- Filtros por estado.
- Gestión de carga y errores.

## Instalación

npm install

## Desarrollo

npm run dev
